# SkillForest - AI Documentation

## Overview

SkillForest is a Flutter application designed to help users develop skills through consistent practice, progress tracking, and a visual tree-growth system.

## AI Functionality

The current version of SkillForest does not include an integrated AI model, chatbot, or external AI API.

The application's main features use Flutter widgets, Dart application logic, and local SQLite storage.

## AI Assistance During Development

ChatGPT was used as a development assistance tool during the project.

Assistance included:
- Explaining Flutter and Dart implementation steps
- Helping troubleshoot development and testing errors
- Providing code suggestions and debugging guidance
- Assisting with project documentation
- Explaining Git and GitHub commands

## Application Features

SkillForest supports:
- Creating, editing, and deleting skills
- Recording practice time and notes
- Tracking progress through a tree-growth theme
- Reviewing practice history
- Viewing learning activity and insights
- Saving information locally using SQLite

These features do not require an internet connection to an AI service.

## Testing and Verification

The project was checked using Flutter's static analyzer and an automated startup configuration test.

Manual testing on an Android emulator confirmed skill creation, editing, deletion, and practice logging.

## Limitations and Future Improvements

SkillForest currently does not generate personalized recommendations using artificial intelligence.

A future version could introduce optional AI-assisted practice suggestions or learning recommendations, but these features are not part of the current implementation.

## Conclusion

SkillForest is a skill-tracking application built with Flutter and Dart. AI tools assisted with aspects of the development process, while the application itself uses conventional programming logic and local data storage.
